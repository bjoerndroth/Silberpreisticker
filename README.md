# Silberpreisticker – Live-Silberpreis in €/kg für Windows
![Silberbarren und Silbermünzen](silberbarren.png)
Ein kleiner Windows-Ticker, der den aktuellen Silberpreis in Euro pro Kilogramm anzeigt.

## Funktionen

- Automatische Kursaktualisierung
- Anzeige des zuletzt gespeicherten Kurses bei vorübergehenden Verbindungsproblemen
- Für Windows 10/11, 64-Bit
## Download

**[Silberpreisticker für Windows herunterladen](https://github.com/bjoerndroth/Silberpreisticker/releases/latest)**

Lade auf der Release-Seite unter „Assets“ die Datei `Silberpreisticker.exe` herunter.

## Hinweis

Der angezeigte Silberpreis ist ein Richtwert und kann von tatsächlichen An- und Verkaufspreisen abweichen.
